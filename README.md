# マークダウン記法チートシート（情報I）

高校「情報I」の「コミュニケーションと情報デザイン」で使う、マークダウン（md）記法のチートシートです。記号（md原文）がHTMLのタグになり、ブラウザで見た目になる流れを、見比べながら覚えられます。

**公開ページ：https://chro05.github.io/md-cheatsheet/**

## 中身

| セクション | 内容 |
|---|---|
| 3枚のシート | md原文 → HTMLタグ → 表示 の3段の図。ドラッグや矢印キーで回し、スライダーで重ねたりばらしたりできる |
| 記法一覧 | 見出し・段落と改行・強調・斜体・打ち消し線・箇条書き・番号付きリスト・チェックリスト・引用・コード・コードブロック・リンク・画像・表・区切り線・エスケープの16種 |
| 毎日シート | 書く練習の欄と、確認問題3問（選択式）、振り返り欄 |
| 指導者向け | 50分の流れ（例）、つまずきやすい所と声かけ、発問と見取り |
| 出典 | 記法の基準と、科目の位置づけ |

## 使い方

- ブラウザで公開ページを開くだけです。インストールやログインはいりません。
- PC・タブレット・スマホで見られます。
- 印刷するとボタン類が消え、1セクションが1ページに収まります。

## ファイル

- `index.html`：ページ本体（HTML・CSS・JavaScriptを1ファイルにまとめたもの）

## 更新のしかた

`index.html` を直して `main` ブランチにコミットすると、1分ほどで公開ページに反映されます（GitHub Pages：main ブランチ / root）。

## 出典

- 記法の基準：[CommonMark Spec Version 0.31.2（2024-01-28）](https://spec.commonmark.org/0.31.2/)
- 表・チェックリスト・打ち消し線：[GitHub Flavored Markdown Spec](https://github.github.com/gfm/)
- 科目の位置づけ：文部科学省[『高等学校学習指導要領（平成30年告示）解説 情報編』](https://www.mext.go.jp/content/1407073_11_1_2.pdf)

例文はこの教材のために作った見本です。
